DiamondSim

A desktop app that plays out the remainder of an MLB season thousands of times and reports each team's odds of making the playoffs. Team ratings are adjusted per game for the starting pitcher, lineup and bullpen fatigue, then the postseason bracket is simulated round by round. Threaded so the interface stays responsive while thousands of seasons run.

RainCheck

A native Android weather app built on the classic View system. It queries several forecast providers at once, rejects the outliers statistically and averages what's left, so a single bad source can't skew your forecast. Three independent notification systems, precipitation classified into five distinct types, and a permission model that actually distinguishes "always" from "while using".

Snake Gone Rogue

Snake, rebuilt as a roguelite. Every run you pick temporary upgrades from a shop, gamble on random modifiers, and try to hit a rising quota before the debt catches you. Permanent upgrades carry between runs through a slot-based save system. Hand-drawn 16×16 sprites, a custom pixel font, a seamless ribbon renderer for the snake body, and an endless mode where the board wraps in both directions.

Human Benchmark Bot

A browser automation tool that plays the Human Benchmark reaction and typing tests, with a Tkinter control panel for picking tests and stopping mid-run. Most of the work was in the failure modes: a stop button that raced the worker thread, XPath selectors that broke on any markup change, busy-wait loops burning CPU, and a typing test that reported 0 WPM because the page never registered the first keystroke — fixed by sending the opening character alone with a short delay, then the rest instantly.

  • Python
  • Selenium
  • Tkinter
  • Threading

Scientific Calculator

A desktop calculator that started as a Tkinter exercise and turned into something I actually use. The maths engine runs on Python's decimal module rather than floats, so results don't drift. There's a settings page for angle mode, precision, notation and digit separators that applies changes live and saves them to disk, plus a unit converter covering eight categories. The interface was rebuilt in CustomTkinter with a slide-out navigation panel.
